商店申請表單

  • 表單填寫約需 5 分鐘，無須上傳任何附件。
  • 填寫前請先詳閱表單中的「填表前必讀」說明，以利順利完成申請。
  • 若資料缺漏而需退回補件，通常會額外增加 1～2 週的作業時間。
前往填寫商店申請表

申請送出後的流程

  1. 新競雲智能股份有限公司檢查資料
  2. 代為送件至統一金流線上註冊
  3. 統一金流線上寄送信箱驗證通知信至聯絡人信箱
  4. 完成信箱驗證後，至統一金流線上官網登錄

寄送 PayUni 特店憑證

完成信箱驗證並登入統一金流線上官網後，請查詢以下三組資訊，並寄送至競賽咖客服信箱。平台核對無誤後，將協助設定 KEY 值並開通金流功能。

如何找到這三組資訊？

登入統一金流線上官網後台後，依下圖標示位置查看 MerchantID、HashKey、HashIV。

步驟二寄送檢附文件至競賽咖客服

請依申請類型準備以下資料，缺件將無法送審。

「法人」公司戶檢附資料

  1. 變更事項登記表完整頁面（商工網站截圖）
  2. 負責人身分證正、反面（清晰可辨識）
  3. 公司戶存摺（不收數位帳戶、籌備處存摺）
  4. 線上：官網截圖（頁首、商品頁、頁尾）
  5. 商品價目表

「社團法人／財團法人」檢附資料

  1. 法人登記證書，或人民團體立案證書＋人民團體職員當選證明書
  2. 統一編配書
  3. 負責人身分證正、反面（清晰可辨識）
  4. 公司戶存摺（不收數位帳戶、籌備處存摺）
  5. 線上：官網截圖（頁首、商品頁、頁尾）
  6. 商品價目表

「商行／商號」檢附資料

  1. 商業登記抄本（商工網站截圖），或國稅局函文（稅籍網站截圖）
  2. 負責人身分證正、反面（清晰可辨識）
  3. 公司戶存摺（不收數位帳戶、籌備處存摺）
  4. 線上：官網截圖（頁首、商品頁、頁尾）
  5. 商品價目表

「個人」檢附資料

  1. 負責人身分證正、反面（清晰可辨識）
  2. 負責人存摺（不收數位帳戶）
  3. 線上：官網截圖（頁首、商品頁、頁尾）
  4. 商品價目表
